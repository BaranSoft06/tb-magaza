# T&B

T&B, Baran ve Taylan'ın kendi tasarladıkları kadın ve erkek kıyafetlerini satacağı bir giyim markası. Gömlek, pantolon, ceket gibi şık ve günlük parçalar üretiyoruz. Bu depo markanın e-ticaret sitesini içeriyor.

**Canlı site:** https://baransoft06.github.io/tb-magaza/

> ⚠️ **Bu bir demo sitedir.** Sitede gerçek satış yapılmaz, gerçek ödeme alınmaz. Ürün görselleri şimdilik örnek görsellerdir.

## Şu ana kadar yapılanlar

**Genel**
- "&" işaretinin dönerek ortaya çıktığı açılış animasyonu
- Üst menü: logo, linkler, sepet ikonu, telefonda hamburger menü
- Sayfanın en üstünde sürekli kayan yazı şeridi
- Markaya uygun özel fare imleci (sadece bilgisayarda)
- Sayfalar arasında yumuşak geçiş animasyonu
- Menüde ürün arama
- Footer: logo, linkler, sosyal medya ve demo notu

**Ana sayfa**
- Karşılama alanı (hero)

**Ürünler sayfası**
- 12 demo ürün (6 kadın, 6 erkek)
- Marka renklerinde yer tutucu görseller
- Tümü / Kadın / Erkek filtresi
- Kaydırdıkça beliren ürün kartları
- Kalp ikonuyla favorilere ekleme
- Açılan pencerede hızlı bakış

## Kullanılan teknolojiler

- HTML
- CSS
- JavaScript

Framework ya da build aracı kullanılmıyor. Favoriler tarayıcıda `localStorage` ile tutuluyor.

## Ekip

- **Baran**: kod
- **Taylan**: ticaret
